PostgreSQL  ·  SQL  ·  Data Cleaning  ·  Business Intelligence

Recruitment Data Collection & Transformation Pipeline

Python  ·  REST APIs  ·  Web Scraping  ·  Pandas  ·  Generative AI  ·  Data Wrangling

Used Generative AI to build a multi-source recruitment data collection system in Python that scrapes live job postings from five job boards across 16 countries via REST APIs, then transforms and enriches the raw data using NLP techniques — producing a clean, structured dataset ready for analysis.

Key Achievements:

  • Integrated five live job board APIs (Reed, Adzuna, The Muse, Remotive, Arbeitnow) with a rotating user-agent pool, polite request delays, and automatic retry logic to collect job postings reliably across 16 countries.
  • Built a 12-hour recurring scheduler with graceful shutdown handling, enabling unattended continuous data collection without manual intervention.
  • Implemented a multi-layer deduplication system — combining exact-match, job ID, MD5 semantic fingerprinting, and URL-based strategies — to eliminate cross-source duplicate postings before transformation.
  • Parsed and normalised raw salary strings (ranges, daily rates, shorthand like "£40k") into consistent annual figures, and standardised relative date formats (e.g. "3 days ago") into ISO dates across all sources.
  • Applied Generative AI techniques for natural language processing and structured data extraction from unstructured job descriptions.
  • Delivered a clean 31-column enriched dataset as CSV, JSON, and a compressed TF-IDF sparse matrix — fully ready for downstream salary benchmarking and skills gap analysis.

Tools: Python · requests · BeautifulSoup · REST APIs · Pandas · Generative AI · Jupyter Notebook
